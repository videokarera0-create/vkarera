Build a 3D horse racing web application using Three.js and Tailwind CSS.
Core Visuals & Rendering:
Implement a realistic 3D dirt race track with dynamic sun lighting, shadows, and subtle ground mist/dust effects.
Include 4 to 6 detailed 3D running horses with smooth galloping animation cycles.
Use a cinematic tracking camera that follows the lead horse in dynamic angles (e.g., side view, broadcast chase cam).
Interactive Features & UI:
Controls: Allow the player to pick a horse, set a bet amount, and start the race.
Live HUD: Display a real-time race leaderboard, speedometer, distance to finish line, and camera toggle buttons (e.g., Tracking Cam, Overhead Cam, Finish Line Cam).
Audio: Add ambient track noise, cheering crowd sounds, and galloping audio synchronized with horse speeds (using Web Audio API or HTML5 Audio).

Each horse should have subtle variations in speed, stamina, and acceleration logic so every race outcome is dynamic and unpredictable.
